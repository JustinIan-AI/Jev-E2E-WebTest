## 0. 逐条评审协议

**三种类别，决定这条由谁回答：**

| 类别 | 含义 | 谁回答 |
|---|---|---|
| **决策** | 我给了建议答案，需要你**通过 / 驳回 / 改** | 你 |
| **实测** | 纸面成立但没跑过，**我可以本机跑出数据**再给你看结论 | 我先跑，你再看数据 |
| **外部** | 依赖被测系统、许可证、第三方数据，**需要外部条件** | 你提供条件或确认接受 |

**四种判定动作：**

| 判定 | 含义 | 我的后续动作 |
|---|---|---|
| ✅ **通过** | 同意（含同意我的建议） | 写入文档 + 决议记录 |
| ✏️ **修改** | 方向对但值/边界要改 | 按你给的值改，并回写所有引用点 |
| ⛔ **驳回** | 不采纳 | 撤回该条，并检查是否有下游设计依赖它 |
| ⏸️ **延后** | 暂不定，登记为待办 | 标注 Mx 前必须关闭，不静默丢失 |

**回复方式**：直接给编号 + 判定即可，例如 `A01 通过`、`D04 修改为 0.55/0.85`、`A03 驳回`。

| **若不通过** | 整份 skill-first 方案的隔离前提不成立（PRD 评审 §6.2） |

### A05 · 稳定性指标改写为「无 flaky case」硬门禁

| 字段 | 内容 |
|---|---|
| **决议** | ①「无 flaky case」**二值硬门禁**（任一 case 连跑 N≥10 次结论不一致 → 判该 case 为缺陷，阻断合并）② suite 绿灯率仅作**观测趋势**，不作门禁阈值 |
| **依据** | PRD 的「单 case ≥95%」不组合。`suite 绿灯率 ≈ p^n`：p=0.95 时 n=50 仅 **7.7%** 全绿 → 门禁 92% 的时间在红。反推：50 case 要 95% 绿灯，单 case 需 **99.9%** |
| **我建议的答案** | ✅ 通过。泛化原则：**比例型通过率不能取平均，必须取幂或改为二值计数** |
| **影响面** | §9.1 · §12 回归 · M4 门禁 |
| **若不通过** | CI 门禁不可用（长期红灯）或被迫放宽到无意义 |
| **通过判据** | §9.1 两条条款成形；`--repeat 10` 能输出 flaky 判定 |
| **⚠️ 附带成本项** | `--repeat 10` 意味着 **耗时 ×10**。这条要不要作为每次 PR 的门禁、还是 nightly 跑，见 D05/E 组。**请连同评审** |
| **判定** | ✅ **通过（2026-09-23）**。判据形态锁定为**二值**（有无 flaky case），绿灯率仅作观测；**§9.1 两条条款须成形**，且 `--repeat 10` 须能输出 flaky 判定 |
| **遗留** | **⚠️ 成本项未决**：`--repeat N` 放每 PR 还是 nightly → 随 **D05** 一起定，勿静默丢失 |

| **H05** | **视觉模型选型：自托管开源 vs 云 API** | 视觉通道的成本与数据合规同时被这一项决定：**云 API 意味着截图（含页面内容，可能含凭据）出内网** → 与 §六 的敏感区域排除叠加后仍可能不达合规要求；自托管则需 GPU | 二选一并确认：**(a) 云 API** —— 需确认截图出内网是否可接受、是否已排除全部敏感区域 **(b) 自托管**（如 Qwen-VL / UI-TARS 系）—— 需 GPU 资源与部署归属 | 🟡 P2 | 待定 |

## J. SUT 中立化（2 项 · 2026-10-10 新增 · 换 SUT 时必跑）

> **背景**：PRD/DD 已按判据「**离开 openFuyao，这条还成立吗？**」把 SUT 专属事实与产品要求分开。本组只关心一件事：**换一个 SUT（非 K8s / 无命名空间 / 有多租户）时，隔离机制是否仍然成立**。E02 的结论**只在 K8s 适配下有效**，因此需要一组「按 SUT 重跑」的验收。

| # | 事项 | 为什么需要验证 | 验证方式 | 优先级 | 判定 |
|---|---|---|---|---|---|
| **J01** | **隔离单元在非 K8s SUT 上的可行性** | 隔离单元已抽象为「run 级作用域，形式由 SUT 决定」；但**除 K8s 外的形式（租户 / 资源名前缀 + 标签集）从未实测** | 取一个**非 K8s 的 B/S 系统**做首个对照 SUT：① 有无原生 scope（租户 / 项目 / 工作区）② 无原生 scope 时，`runId + contractId` 前缀 + 标签集能否让断言只命中本次创建集 ③ cleanup 能否轮询至终态 | 🔴 P1 | 待定 |
